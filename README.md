## 产品简介

OSPTEK **2.14 寸 480×480 AMOLED** 是一款 **QSPI** 接口显示模组，驱动为 **ST7801N**，触摸为 **CST9220**。

规格标识（仓库名）：`2.14-amoled-480x480-qspi-st7801`

## 规格参数

| 项目 | 规格 |
| ---- | ---- |
| 尺寸 | 2.14 英寸 |
| 类型 | AMOLED 模组 |
| 分辨率 | 480×480 |
| 接口 | QSPI |
| 驱动 IC | ST7801N |
| 触摸驱动 | CST9220 |

> 完整外形尺寸、FPC 定义、供电与时序以产品规格书 / 驱动手册为准。
