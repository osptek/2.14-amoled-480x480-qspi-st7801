## Overview

OSPTEK **2.14″ 480×480 AMOLED** is a **QSPI** display module driven by **ST7801N**, with **CST9220** touch.

Spec ID (repository name): `2.14-amoled-480x480-qspi-st7801`

## Specifications

| Item | Spec |
| ---- | ---- |
| Size | 2.14 inch |
| Type | AMOLED module |
| Resolution | 480×480 |
| Interface | QSPI |
| Driver IC | ST7801N |
| Touch driver | CST9220 |

> Full outline, FPC definition, power, and timing follow the product datasheet / driver IC datasheet.
